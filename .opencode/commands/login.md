# Login Command

Please execute the following authentication flow:

1. Parse the arguments: username and token
2. Store credentials in ~/.config/opencode/.edk2_login
3. Confirm login success
4. Enable all skills and MCP services

If the user is already logged in, show current login status.

Arguments: $ARGUMENTS
